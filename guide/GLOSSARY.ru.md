## Краткий словарь

*Краткий разбор терминов из результатов.*

- **n.s.** — незначимо: различие слишком мало, чтобы считать его реальным.
- **p-значение** — вероятность того, что результат случаен; p < 0,05 = менее 5% (например, 6e-5 = 0,00006).
- **ρ (rho)** — показатель согласия методов от 0 до 1; ρ = 0,88 = очень высокое согласие.
- **псевдорепликация** — снимки одной чашки считаются 1 репликатом, а не многими; поэтому p-значения только описательные.
- **N=2 цикла** — результат по счёту опирается лишь на 2 независимых запуска эксперимента.
- **описательно** — p-значения даны только для масштаба и направления, не как формальное доказательство.
- **смена знака** — цикл 1 показал порядок, обратный циклам 2–3.
- **конечная точка (эндпойнт)** — снимок одного момента, а не съёмка клеток во времени.
- **CH0/CH17/CH19/CH21** — настройки излучателя; CH0 = выключен (контроль), CH17/19/21 = три конфигурации поля.
- **занятость** — доля площади снимка, занятая клетками (0 = пусто, 1 = полностью).

## Термины

### Статистика

| Термин | Значение |
|---|---|
| **n.s.** | Незначимо / статистически не значимо — различие между группами слишком мало, чтобы исключить случайность |
| **p / p-value** | Число от 0 до 1: вероятность того, что наблюдаемое различие возникло случайно. p < 0,05 = менее 5% вероятности случайности. Запись 6e-5 = 0,00006 (меньше = менее вероятна случайность) |
| **descriptive p-value** | p приводится только для справки о масштабе/направлении, не как формальная проверка — допущение о независимости нарушено (см. псевдорепликация) |
| **pseudoreplication** | Несколько снимков одной чашки Петри считаются независимыми; завышает выборку и занижает p. Настоящие репликаты — 3 цикла эксперимента, а не отдельные снимки |
| **N=2 cycles** | Результат по счёту клеток опирается лишь на 2 независимых повторения; слишком мало для статистической проверки на уровне цикла |
| **ρ (rho) / Spearman correlation** | Число от −1 до +1, показывающее согласованность ранжирования двух методов. ρ = 0,88 = очень высокое согласие |
| **Kruskal–Wallis** | Статистический тест для сравнения 3 и более групп без допущения о нормальном распределении |
| **Δ (delta)** | Разность двух значений (например, Δ ecc = 0,016 — эксцентриситет отличается на 0,016 единицы) |
| **LME (Linear Mixed-Effects Model)** | Статистическая модель для данных с повторными измерениями; разделяет эффекты воздействия и случайную изменчивость |
| **Tukey HSD** | Пост-хок тест попарных сравнений всех групп при контроле ложных срабатываний |
| **Bonferroni** | Поправка при многочисленных одновременных тестах; делит порог значимости на число тестов |
| **Cohen's d** | Размер эффекта: сколько стандартных отклонений между средними двух групп (d ≥ 0,8 большой, ≈0,5 средний, ≈0,2 малый) |
| **partial eta squared** | Размер эффекта: доля общей дисперсии, объясняемой воздействием (0–1; больше = сильнее) |
| **AUC (Area Under the Curve)** | Суммарная площадь под кривой временного ряда; измеряет суммарную активность ферментации за весь период |
| **sign-flip** | Направление эффекта поменялось на противоположное (цикл 1 показал порядок, обратный циклам 2–3) |
| **a priori** | Известное или предсказанное до эксперимента; CH17 «априори неизвестен» = прогноза не было |
| **R²** | R²: мера качества подгонки модели (0–1). R² = 0,81 = объяснён 81% дисперсии |

### Компьютерное зрение

| Термин | Значение |
|---|---|
| **Cellpose / cyto2** | Программа ИИ с открытым кодом для автоматического обнаружения и обводки клеток; «cyto2» — её нейросетевая модель, обученная на изображениях тела клетки |
| **segmentation / instance segmentation** | Определение пикселей каждой клетки и обводка границы; «инстанционная» = каждая клетка обводится отдельно |
| **CNN (Convolutional Neural Network)** | Тип ИИ для распознавания клеток, обученный на множестве примеров изображений |
| **occupancy / texture occupancy** | Доля площади снимка, занятая клетками (0 = пусто, 1 = полностью), измеряется по яркости пикселей без обводки клеток |
| **Otsu** | Алгоритм автоматического нахождения порога яркости между клетками и фоном |
| **Canny** | Алгоритм обнаружения краёв; здесь считает края клеток как косвенный показатель плотности |
| **field (microscopy field / FOV)** | Один снимок через микроскоп (990 полей = 990 фотографий) |
| **eccentricity** | Метрика формы клетки (0–1): 0 = круг, 1 = линия; выше = более вытянута |
| **aspect ratio (major:minor axis)** | Отношение длиннейшего к кратчайшему диаметру вписанного эллипса; 1,0 = круг, больше = вытянутее |
| **solidity** | Метрика компактности контура клетки (0–1); почкующаяся клетка имеет меньшую солидность |
| **blob detection** | Поиск клеток как округлых заполненных областей без нейросетевой сегментации |
| **downscale** | Уменьшение числа пикселей перед обработкой; стандартизирует размер клеток и ускоряет анализ |
| **100× / 10× magnification** | Объекты выглядят в 100 или 10 раз крупнее; при 100× видны отдельные клетки (~5–8 мкм), при 10× — только плотность популяции |
| **HEIC** | Формат фотографий iPhone; здесь — снимки через окуляр микроскопа смартфоном |
| **YeastSAM** | Инструмент ИИ-сегментации для почкующихся дрожжей; точнее Cellpose на почкующихся клетках |
| **AMiGA** | Программа для подгонки кривых роста микробов (скорость роста, лаг-фаза) гауссовским процессом |
| **CIELAB / b\* channel** | Система описания цвета; канал b\* измеряет синий/жёлтый сдвиг, для обнаружения захвата метиленового синего |

### AI-метод

| Термин | Значение |
|---|---|
| **blind LLM scoring** | ИИ-модель оценивала каждый снимок, не зная, из какого канала он взят — исключает предвзятость; «слепой» = оценщик не знает группу |
| **group-agnostic** | Метод не видит метки каналов до финального шага группировки |
| **diagnostic vs consistent** | «Согласуется с» = совместимо с гипотезой, но не доказывает; «диагностический» = однозначно указывает на одну причину |

### Биология

| Термин | Значение |
|---|---|
| **budding index / budding fraction** | Доля дрожжевых клеток, активно делящихся в момент съёмки — видна как «почка» на материнской клетке; выше = активнее деление |
| **Whi5 / G1-sizer** | Whi5 — белок-тормоз деления; механизм G1-сайзера позволяет клетке «измерить» размер перед делением. Клетки, прошедшие «Start» маленькими, дают мелких дочерей |
| **Start (cell cycle)** | Молекулярная «точка невозврата» клеточного цикла, после которой клетка обязана начать деление |
| **G2/M arrest** | Клетки застряли прямо перед делением; выглядят готовыми (с почками), но деление не завершается — трудно отличить от быстрого деления на одном снимке |
| **time-lapse microscopy** | Многократная съёмка одних и тех же клеток на протяжении часов; прямо измеряет скорость деления, в отличие от одиночного снимка |
| **OD600 / doubling time** | OD600 = мутность жидкости при свете 600 нм; при размножении клеток растёт. Время удвоения = время удвоения численности; быстрее деление = меньше время |
| **stationary phase** | Когда питание исчерпано, дрожжи перестают делиться и переходят в покой; такие клетки мельче и могут имитировать уменьшение CH19 |
| **quiescent cells** | Отдельные недепящиеся, спящие клетки; меньше активно растущих |
| **viability / vital stain** | Краситель, отличающий живые клетки от мёртвых; метиленовый синий красит мёртвые в синий, живые остаются прозрачными. НЕ применялся в первом пакете |
| **kinetic effect** | Влияние на скорость деления клеток (не на их количество) |
| **morphological effect** | Влияние на форму или размер клеток |
| **morphometry** | Количественное измерение формы, размера и геометрии клеток (площадь, вытянутость, округлость) |
| **endpoint / static endpoint / конечная точка (эндпойнт)** | Одно измерение в один момент (не временной ряд); показывает только состояние клеток на снимке, не их изменение |
| **confound / imaging confound** | Неконтролируемый фактор помимо воздействия, который мог бы объяснить различие (разная фокусировка, разведение, освещение между каналами) |

### Дизайн исследования

| Термин | Значение |
|---|---|
| **CH0 / CH17 / CH19 / CH21 (channels)** | Конкретные конфигурации излучателя; CH0 = выключен (контроль), CH17/19/21 = три разные настройки. Числа — идентификаторы из ПО управления, а не физические частоты |
| **cycles 001 / 002 / 003** | Три независимых повторения всего эксперимента (биологические репликаты), каждый со свежими дрожжами |
| **biological replicate** | Независимое повторение со свежими образцами (в отличие от повторного измерения того же образца) |
| **preregistration / OSF** | Публичное, заверенное временны́м штампом объявление гипотез и плана анализа до сбора данных; не даёт подогнать анализ под результаты. OSF (Open Science Framework) — бесплатный публичный реестр, фиксирующий его |
| **double-blind** | Ни аналитик, ни оценивающая система (LLM) не знают принадлежности образца к условию во время оценки |
